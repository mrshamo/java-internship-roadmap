# Introduction

Java is one of the most popular programming languages because it follows the principle:

Write Once, Run Anywhere (WORA)

This means a Java program can run on different operating systems as long as a Java environment is installed.

 # JDK (Java Development Kit)

The JDK is a complete package used by developers to create Java applications.

It contains:

JRE (Java Runtime Environment)
Java Compiler (javac)
Development tools and utilities

Think of the JDK as a toolbox for Java developers.

Example

When writing and compiling Java code, you need the JDK installed on your computer.

JRE (Java Runtime Environment)

The JRE provides everything needed to run Java programs.

It contains:

JVM (Java Virtual Machine)
Java libraries and runtime files

Think of the JRE as a player that runs Java applications.

Example

If a user only wants to run a Java application and not develop one, the JRE is sufficient.

JVM (Java Virtual Machine)

The JVM is the component responsible for executing Java bytecode.

Main responsibilities:

Loads bytecode
Verifies code for security
Converts bytecode into machine code
Executes the program

The JVM acts as a bridge between Java programs and the operating system.

Example

A Java program compiled on Windows can run on Linux because both systems have their own JVM implementation.

javac (Java Compiler)

javac is the Java compiler included in the JDK.

Its job is to convert Java source code into bytecode.

Command
Shell
javac Main.java
Input
Plain Text
Main.java
Output
Plain Text
Main.class

The generated .class file contains bytecode.

Bytecode

Bytecode is an intermediate code produced by the Java compiler.

Characteristics:

Platform independent
Stored in .class files
Executed by the JVM

Bytecode is the reason Java programs can run on multiple operating systems without modification.

java Command

The java command is used to run a compiled Java program.

Command
Shell
java Main

The JVM loads the bytecode from Main.class and executes it.

Complete Execution Flow

Summary
JDK = Development kit for creating Java programs.
JRE = Environment required to run Java programs.
JVM = Executes Java bytecode.
javac = Compiles .java files into .class files.
Bytecode = Platform-independent code generated by the compiler.
java = Command used to run compiled Java programs.

Understanding these components is essential for Java development and is a common interview topic for beginner and intermediate Java developers.
